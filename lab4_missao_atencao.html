Por que model.eval()?

Sem isso, o Dropout permanece ativo e a geração fica não-determinística mesmo com temperatura 0.

from transformers import GPT2LMHeadModel, GPT2Tokenizer
model_name = "gpt2-medium"  # 345M parâmetros
tokenizer = GPT2Tokenizer.from_pretrained(model_name)
model = GPT2LMHeadModel.from_pretrained(model_name, output_attentions=True)
model.eval()  # desliga dropout → geração determinística

3️⃣ Nível 3 · Geração Autoregressiva

O GPT-2 nunca "vê" o futuro — ele gera um token por vez, e cada token vira contexto para o próximo. É por isso que erros se propagam.
